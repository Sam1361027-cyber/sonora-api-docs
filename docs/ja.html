Sonora API 1.0.0 · Minecraft 1.21.1 · NeoForge

開発者ガイド

サーバーに登録した MP3 を、音源の周囲や指定グループのプレイヤーに配信できます。参加者はクライアントに Sonora を導入すると、再生中の曲にも途中から参加できます。

導入

Java 21、Minecraft 1.21.1、NeoForge 21.1.233 以上の 21.1 系を使用します。作者から入手した公式 JAR をサーバーとクライアントの mods に配置します。開発時は連携 MOD の libs に置き、build.gradle に次を追加します。

dependencies {
    implementation files('libs/sonora-NeoForge-MC1.21.1-1.0.0.jar')
}

src/main/resources/META-INF/neoforge.mods.toml に実行時依存を追加します。gallery は連携 MOD の ID に置き換えてください。この例は対象を記載バージョンに固定します。

[[dependencies.gallery]]
modId = "sonora"
type = "required"
versionRange = "[1.0.0]"
ordering = "NONE"
side = "BOTH"

音源を登録する

例で使用する theme.mp3 と bell.mp3 を、MOD ID が gallery の連携 MOD の src/main/resources/data/gallery/audio_library/ に配置します。サーバー起動時に gallery:theme と gallery:bell として登録されます。ワールド内の audio_library/gallery/ に置く方法もあります。管理者は /audio list gallery で登録を確認できます。

再生と同期

ワールドに音源を置く

var room = SonoraAPI.playAt(level, speaker, "gallery:theme", 4f, 32f, 0.8f);

論理サーバーのスレッドで一度呼びます。ブロック中心から4ブロック以内は80%、32ブロックまで直線的に減衰します。同じディメンション内の出入りを追跡します。距離には 0 ≤ fullDistance < silentDistance を満たす有限値を指定します。戻り値を保持すると後から操作できます。

グループで同期再生する

var tour = AudioLibrary.get(level.getServer()).play(trackId, List.of(guide));
// Later, when another player joins:
tour.addListener(visitor, ServerAudioPlayback.JoinMode.CURRENT_POSITION);

同じセッションのハンドルを共有すると、途中参加者はサーバーの現在位置から聴けます。play を個別に呼ぶと別セッションになります。実際の聞こえ始めには先読み、端末、回線による差があります。

フェード・一時停止・シーク・停止

room.fadeTo(0.25f, 1500);

1.5秒で音量25%まで変化します。停止するタイミングで room.close() を呼んでください。直後に閉じるとフェードも打ち切られます。room.pause() と room.resume() でセッションを維持したまま一時停止・再開できます。5秒より長い曲なら room.seekTo(5000L) で5秒地点へ移動できます。

API リファレンス

型名を開くと完全修飾名、呼び出しシグネチャ、利用条件を確認できます。引数型は宣言順です。クライアント専用の型は連携 MOD のクライアント側から使用してください。

SonoraAPIjp.suzuk.sonora.api.SonoraAPI

登録済みの曲 ID（文字列または ResourceLocation）とブロック位置を指定します。最後の引数は等音量距離、無音距離、基本音量の順です。サーバースレッドで ServerLevel を渡します。

static SonoraAPI.Playback playAt(Level, BlockPos, String, float, float, float);
static SonoraAPI.Playback playAt(Level, BlockPos, ResourceLocation, float, float, float);
SonoraAPI.Playbackjp.suzuk.sonora.api.SonoraAPI.Playback

ハンドルをイベント間で保持します。pause と resume は状態が変化した場合に true を返します。seekTo の単位はミリ秒で、0 以上、曲の長さ未満です。範囲外は IllegalArgumentException です。close で停止します。

UUID id();
boolean pause();
boolean resume();
boolean seekTo(long);
void setVolume(float);
void fadeTo(float, int);
void close();
SonoraEventsjp.suzuk.sonora.api.SonoraEvents

起動後のサーバースレッドで登録します。TimeCue は level、tickOfDay、dayTime を返します。指定時刻（0～23999）を順方向に通過した更新で一度通知し、睡眠にも対応します。StructureCue は level、player、structure、boundary（ENTER / EXIT）、position を返します。ロード済みチャンクを5 tick間隔で調べるため、短い通過を見逃す場合があります。MobCue は level、mob、action（ADDED / DEATH）、position を返し、ADDED は保存済み Mob の読み込みを除きます。DimensionCue は player、from、to を返します。

static SonoraEvents of(MinecraftServer);
SonoraEvents.Subscription onTime(ServerLevel, int, Consumer<SonoraEvents.TimeCue>);
SonoraEvents.Subscription onStructure(ServerLevel, ResourceLocation, Consumer<SonoraEvents.StructureCue>);
SonoraEvents.Subscription onMob(EntityType<? extends Mob>, SonoraEvents.MobAction, Consumer<SonoraEvents.MobCue>);
SonoraEvents.Subscription onDimensionChange(Consumer<SonoraEvents.DimensionCue>);
SonoraEvents.Subscriptionjp.suzuk.sonora.api.SonoraEvents.Subscription

サーバースレッドで close を呼ぶと解除できます。サーバー停止時に購読は破棄されます。

void close();
AudioLibraryjp.suzuk.vhaudio.AudioLibrary

サーバー単位の曲カタログです。未知の ID では info は null、source は例外を返します。TrackInfo の項目は id、durationMillis、bytes、stored です。出所は MOD_BUNDLE、WORLD_FILE、RUNTIME のいずれかです。同梱曲は読み取り専用で、二重登録は失敗します。registerPersistent の完了までは元ファイルを保持し、サーバースレッドで同期待機しないでください。delete はワールド保存曲のファイルも削除します。

ServerAudioPlaybackjp.suzuk.vhaudio.ServerAudioPlayback

CURRENT_POSITION は共有タイムラインの現在位置に参加します。FROM_START は指定プレイヤー用に別のセッションを返します。Snapshot は sessionId、namespace、任意の trackId、phase、positionMillis、durationMillis、looping、listeners を返します。phase は PREPARING、PLAYING、PAUSED、ENDED です。completion の結果は FINISHED、STOPPED、SERVER_STOPPING のいずれかで、クライアントの再生完了とは時間差があります。

PlaybackOptionsjp.suzuk.vhaudio.PlaybackOptions

コンストラクタはカテゴリ、音量（0～1）、減衰関数、先読み（100～3000 ms）、遅延許容（0～10000 ms、遅れによる破棄を無効にする場合は −1）、ループの順です。DEFAULT は MUSIC、1、GLOBAL、1000、250、false です。linear はディメンション、中心座標、2つの距離（ブロック）を取ります。

Mp3Trackjp.suzuk.vhaudio.Mp3Track

ローカル MP3 はサーバースレッド外で読み込み、結果をサーバースレッドで登録します。長さはミリ秒単位です。

static Mp3Track load(Path) throws IOException;
long durationMillis();
AudioPermissionsjp.suzuk.vhaudio.AudioPermissions

名前空間単位でコマンド権限を登録します。操作は VIEW、PLAY、CONTROL、DELETE、UPLOAD です。独自ポリシーはコンソールを含む既定の判定を置き換えます。連携 MOD が直接プレイヤー要求を受ける場合は入口で権限を確認します。

static void register(String, BiPredicate<CommandSourceStack, AudioPermissions.Action>);
static boolean allowed(CommandSourceStack, String, AudioPermissions.Action);
ClientAudioUploadjp.suzuk.vhaudio.ClientAudioUpload

クライアント専用です。クライアントスレッドで利用者が選んだファイルと曲 ID を渡し、返されるステージで成功・失敗を処理します。サーバー側のアップロード権限が必要です。

static CompletionStage<ResourceLocation> upload(Path, ResourceLocation);
ClientPlaybackEventjp.suzuk.vhaudio.ClientPlaybackEvent

クライアント専用です。NeoForge.EVENT_BUS で購読します。状態は WAITING、OUTPUT_STARTED、REBUFFERING、RECOVERED、ENDED、STOPPED、FAILED です。失敗時は detail を確認します。

UUID session();
ClientPlaybackEvent.State state();
long positionMillis();
String detail();

サンプルコード

GalleryAudio.java · 連携 MOD から使うクラスの全体例です。各メソッドをサーバー側のハンドラーから呼びます。グループごとに1つの tour を保持し、夜の通知が不要になったら購読を close します。

package example.gallery;

import java.util.List;
import jp.suzuk.sonora.api.SonoraAPI;
import jp.suzuk.sonora.api.SonoraEvents;
import jp.suzuk.vhaudio.AudioLibrary;
import jp.suzuk.vhaudio.ServerAudioPlayback;
import net.minecraft.core.BlockPos;
import net.minecraft.resources.ResourceLocation;
import net.minecraft.server.level.ServerLevel;
import net.minecraft.server.level.ServerPlayer;

public final class GalleryAudio {
    private static final ResourceLocation THEME =
            ResourceLocation.fromNamespaceAndPath("gallery", "theme");

    public static SonoraAPI.Playback openRoom(ServerLevel level, BlockPos speaker) {
        return SonoraAPI.playAt(level, speaker, THEME, 4f, 32f, 0.8f);
    }

    public static ServerAudioPlayback startTour(ServerLevel level, ServerPlayer guide) {
        return AudioLibrary.get(level.getServer()).play(THEME, List.of(guide));
    }

    public static void joinTour(ServerAudioPlayback tour, ServerPlayer visitor) {
        tour.addListener(visitor, ServerAudioPlayback.JoinMode.CURRENT_POSITION);
    }

    public static void lowerVolume(SonoraAPI.Playback audio) {
        audio.fadeTo(0.25f, 1500);
    }

    public static void stop(SonoraAPI.Playback audio) {
        audio.close();
    }

    public static SonoraEvents.Subscription eveningBell(ServerLevel level, BlockPos bell) {
        return SonoraEvents.of(level.getServer()).onTime(level, 13000, cue ->
                SonoraAPI.playAt(cue.level(), bell, "gallery:bell", 3f, 20f, 0.6f));
    }
}

利用条件

掲載したサンプルコードと GalleryAudio.java は、商用を含むご自身の MOD で複製・改変・再配布できます。この許可の対象はサンプルコードのみです。Sonora API 本体はプロプライエタリです。公開 API の利用には作者の条件が適用され、本体の改造・再配布には権利者の許可が必要です。
