Sonora API 1.0.1 · Minecraft 1.21.1 · NeoForge

Developer guide

Stream a registered MP3 from a Minecraft server to nearby players or a selected group. Players need Sonora on their client and can join a track already in progress.

Installation

Use Java 21, Minecraft 1.21.1 and NeoForge 21.1.233 or later in the 21.1 series. Obtain the official Sonora JAR from its author. Install it in both the dedicated server and client mods folders. For development, place a copy in the consuming project’s libs directory and add this to build.gradle.

dependencies {
    implementation files('libs/sonora-NeoForge-MC1.21.1-1.0.1.jar')
}

Declare the runtime dependency in src/main/resources/META-INF/neoforge.mods.toml. Replace gallery with your own mod ID. This range pins the integration to the documented version.

[[dependencies.gallery]]
modId = "sonora"
type = "required"
versionRange = "[1.0.1]"
ordering = "NONE"
side = "BOTH"

Version 1.0.1 supports uploads and persistent imports up to and including 60 minutes and 144 MiB per track. The world catalog has a 320 MiB budget. Existing 1.0.0 worlds retain their tracks and IDs.

Register the audio

For the examples, bundle theme.mp3 and bell.mp3 under src/main/resources/data/gallery/audio_library/ in the mod whose ID is gallery. At server startup these become gallery:theme and gallery:bell. Alternatively put the files under audio_library/gallery/ inside the world directory. Check registration with /audio list gallery as an operator.

Playback

A speaker in the world

var room = SonoraAPI.playAt(level, speaker, "gallery:theme", 4f, 32f, 0.8f);

Call once on the logical server thread. Volume is 80% within four blocks of the block center. It falls linearly to silence at 32 blocks. Membership follows players in the same dimension. Distances must be finite, with 0 ≤ fullDistance < silentDistance. Keep the handle to control this playback later.

One timeline for a group

var tour = AudioLibrary.get(level.getServer()).play(trackId, List.of(guide));
// Later, when another player joins:
tour.addListener(visitor, ServerAudioPlayback.JoinMode.CURRENT_POSITION);

Share one session handle. A late listener follows its server position. Separate play calls create independent sessions. Buffering, device output and network delay can affect the audible start time.

Fade, pause, seek and stop

room.fadeTo(0.25f, 1500);

This fades to 25% over 1.5 seconds. Call room.close() from a later event to stop. Closing immediately would cut the fade short. Use room.pause() and room.resume() to keep the session; room.seekTo(5000L) moves to five seconds in a track longer than five seconds.

API reference

Expand a type to see its package, callable signatures and usage contract. Parameter types are shown in declaration order. Client-only types belong in your client-side integration.

SonoraAPIjp.suzuk.sonora.api.SonoraAPI

Choose a block position and a registered track ID (string or ResourceLocation). The final three floats are full-volume distance, silent distance and base volume. Use a ServerLevel on the server thread.

static SonoraAPI.Playback playAt(Level, BlockPos, String, float, float, float);
static SonoraAPI.Playback playAt(Level, BlockPos, ResourceLocation, float, float, float);
SonoraAPI.Playbackjp.suzuk.sonora.api.SonoraAPI.Playback

Keep this handle across events. Pause and resume report a state change. Seek uses an absolute offset in milliseconds, from zero up to but excluding the track duration. Invalid offsets throw IllegalArgumentException. Close stops this session.

UUID id();
boolean pause();
boolean resume();
boolean seekTo(long);
void setVolume(float);
void fadeTo(float, int);
void close();
SonoraEventsjp.suzuk.sonora.api.SonoraEvents

Register on the server thread after startup. TimeCue exposes level, tickOfDay and dayTime. A forward crossing of the chosen tick (0–23999) fires once per update, even across sleep. StructureCue exposes level, player, structure, boundary (ENTER / EXIT) and position. Structure pieces are sampled every five ticks in loaded chunks, so short visits may be missed. MobCue exposes level, mob, action (ADDED / DEATH) and position. ADDED excludes disk loads. DimensionCue exposes player, from and to.

static SonoraEvents of(MinecraftServer);
SonoraEvents.Subscription onTime(ServerLevel, int, Consumer<SonoraEvents.TimeCue>);
SonoraEvents.Subscription onStructure(ServerLevel, ResourceLocation, Consumer<SonoraEvents.StructureCue>);
SonoraEvents.Subscription onMob(EntityType<? extends Mob>, SonoraEvents.MobAction, Consumer<SonoraEvents.MobCue>);
SonoraEvents.Subscription onDimensionChange(Consumer<SonoraEvents.DimensionCue>);
SonoraEvents.Subscriptionjp.suzuk.sonora.api.SonoraEvents.Subscription

Close on the server thread to unsubscribe. Subscriptions expire at server shutdown.

AudioLibraryjp.suzuk.vhaudio.AudioLibrary

One catalog per server. info returns null for an unknown ID. TrackInfo exposes id, durationMillis, bytes and stored. source returns MOD_BUNDLE, WORLD_FILE or RUNTIME and rejects unknown IDs. Bundled tracks are read-only. Duplicate registration fails. registerPersistent returns a completion stage; keep the local file readable until it completes and never block the server thread waiting for it. delete also removes a world-backed file.

ServerAudioPlaybackjp.suzuk.vhaudio.ServerAudioPlayback

Use CURRENT_POSITION for a late listener on the shared timeline. FROM_START returns a separate session for that player. Snapshot exposes sessionId, namespace, trackId (optional), phase, positionMillis, durationMillis, looping and listeners. Phases are PREPARING, PLAYING, PAUSED and ENDED. completion reports FINISHED, STOPPED or SERVER_STOPPING on the server timeline; client audio output may finish later.

Constructor order: category, volume (0–1), attenuation function, prebuffer (100–3000 ms), late tolerance (0–10000 ms, or −1 to keep late audio), loop. DEFAULT uses MUSIC, 1, GLOBAL, 1000, 250 and false. linear uses a dimension, center and two distances in blocks.

Mp3Trackjp.suzuk.vhaudio.Mp3Track

Load a local MP3 off the server thread. Register the result on the server thread. Duration is in milliseconds.

AudioPermissionsjp.suzuk.vhaudio.AudioPermissions

Register a command permission policy per namespace. Actions are VIEW, PLAY, CONTROL, DELETE and UPLOAD. A custom policy replaces the default for that namespace, including console requests. Check authorization at your own player-facing entry points.

static void register(String, BiPredicate<CommandSourceStack, AudioPermissions.Action>);

ClientAudioUploadjp.suzuk.vhaudio.ClientAudioUpload

Client only. Submit a user-selected local file and track ID on the client thread. Handle success or failure through the completion stage. Requires server upload permission.

Example code

GalleryAudio.java · A complete integration class. Call its methods from your mod’s server-side handlers. Keep one tour per group, and close the evening subscription when you no longer need it.

package example.gallery;

import java.util.List;
import jp.suzuk.sonora.api.SonoraAPI;
import jp.suzuk.sonora.api.SonoraEvents;
import jp.suzuk.vhaudio.AudioLibrary;
import jp.suzuk.vhaudio.ServerAudioPlayback;
import net.minecraft.core.BlockPos;
import net.minecraft.resources.ResourceLocation;
import net.minecraft.server.level.ServerLevel;
import net.minecraft.server.level.ServerPlayer;

public final class GalleryAudio {
    private static final ResourceLocation THEME =
            ResourceLocation.fromNamespaceAndPath("gallery", "theme");

    public static SonoraAPI.Playback openRoom(ServerLevel level, BlockPos speaker) {
        return SonoraAPI.playAt(level, speaker, THEME, 4f, 32f, 0.8f);
    }

    public static ServerAudioPlayback startTour(ServerLevel level, ServerPlayer guide) {
        return AudioLibrary.get(level.getServer()).play(THEME, List.of(guide));
    }

    public static void joinTour(ServerAudioPlayback tour, ServerPlayer visitor) {
        tour.addListener(visitor, ServerAudioPlayback.JoinMode.CURRENT_POSITION);
    }

    public static void lowerVolume(SonoraAPI.Playback audio) {
        audio.fadeTo(0.25f, 1500);
    }

    public static void stop(SonoraAPI.Playback audio) {
        audio.close();
    }

    public static SonoraEvents.Subscription eveningBell(ServerLevel level, BlockPos bell) {
        return SonoraEvents.of(level.getServer()).onTime(level, 13000, cue ->
                SonoraAPI.playAt(cue.level(), bell, "gallery:bell", 3f, 20f, 0.6f));
    }
}
